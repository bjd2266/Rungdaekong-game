렁대콩의 모험 ONLINE — 통합랭킹 버전

중요:
이 버전은 Netlify Functions + Netlify Blobs를 사용하므로 단순 Netlify Drop(정적 파일 드래그)만으로는 통합랭킹 서버가 동작하지 않을 수 있습니다.

가장 쉬운 배포 방법:
1. ZIP을 풀고 폴더 내용을 GitHub 새 저장소에 업로드합니다.
2. Netlify → Add new project → Import an existing project → GitHub 저장소 선택.
3. Build command는 비워두고, Publish directory는 "." 로 둡니다.
4. Deploy site.
5. 배포 완료 후 같은 주소를 열면 통합랭킹이 작동합니다.

기능:
- 전 사용자 공용 TOP 10
- 닉네임별 최고점수만 저장
- 게임오버 시 자동 등록
- 서버 측 기본 점수 검증
- 2단 점프 / 보스전 / 5종 스킨 / BGM / 공유
